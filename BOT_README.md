# Telegram-бот HackAlem AI

Telegram `/run` → `scripts.local_eval.run_demo(42)` → `Agent.act(env)` → общий скоринг → отчёт и SQLite.

В режиме `real` бот запускает агента на локальной мок-среде организатора. Пилоты и финальные кампании оцениваются вместе. Режим `mock` возвращает фиксированные демонстрационные цифры. Бот не делает рассылку абонентам оператора.

## Запуск

Установка зависимостей и описание конфигурации — в [README.md](README.md). Все команды ниже выполняются из корня репозитория.

1. Скопируйте `config.example.json` в `config.json`, если личного файла ещё нет.
2. В корневом `.env` задайте полный токен своего бота от [@BotFather](https://t.me/BotFather):

   ```dotenv
   TELEGRAM_BOT_TOKEN=ваш_токен
   ```

3. Запустите `start_bot.cmd` двойным щелчком или командой `.\start_bot.cmd`.
4. Откройте ссылку на бота в терминале, отправьте `/start`, затем `/run`.

Окно должно оставаться открытым, пока работает бот. Остановка — `Ctrl+C`. Запускайте один процесс на один токен и одну базу. Публичный сервер и webhook не нужны; накопленные старые команды при старте отбрасываются.

Токен из окружения терминала имеет приоритет над `.env`. Из `.env` читается только `TELEGRAM_BOT_TOKEN`; остальные настройки и ключ Gemini берутся из `config.json`. Оба личных файла исключены из Git.

## Команды и история

| Команда | Действие |
|---|---|
| `/start`, `/help` | Справка и режим работы. |
| `/run` | Один прогон с seed=42, метрики и список кампаний. |
| `/last` | Последний запуск текущего чата, включая ошибку или состояние выполнения. |
| `/history` | Последние пять запусков, новые сверху. |

Одновременно выполняется один `/run`; история остаётся доступной во время расчёта. При падении агента уже выполненные пилоты учитываются в метриках, а запуск помечается ошибкой. Отрицательный результат или статус оценки `FAIL` сами по себе не считаются исключением.

SQLite по умолчанию находится в `data/bot/runs.sqlite3`. Она хранит время, chat ID, seed, режим, состояние, метрики, кампании, число пилотов и ошибку. В группе история общая, в личном чате — только его история. Перезапуск бота сохраняет результаты; прерванный прогон получает состояние ошибки.

## Проверка без Telegram

```powershell
# Настройки и наличие токена, без сети и вывода секретов
.\.venv\Scripts\python.exe -m scripts.bot --check-config

# Агент, пилоты, скоринг и SQLite
.\start_bot.cmd --once

# Фиксированный демонстрационный ответ
.\start_bot.cmd --demo

# Тесты без Telegram и Gemini
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

`--once` может обращаться к Gemini, если модель включена в JSON. Офлайн-записи используют `chat_id=0` и не попадают в историю Telegram-чатов. Флаги `--backend` и `--db` переопределяют настройки на один запуск; относительный путь к базе считается от корня проекта.

## Проверка соединения

При обычном запуске бот проверяет токен через Telegram `getMe`. Проверка без polling:

```powershell
.\.venv\Scripts\python.exe -m scripts.bot --check-telegram
```

Если Telegram отклонил токен (`InvalidToken` / `Unauthorized`), получите новый у BotFather: `/mybots` → ваш бот → **API Token**, обновите `.env` и повторите запуск. Если токен был раскрыт, сначала отзовите его через **Revoke current token**. Ключ Gemini для исправления этой ошибки менять не нужно.

Если старый токен остался в окружении PowerShell, удалите его перед запуском, чтобы использовать `.env`:

```powershell
Remove-Item Env:TELEGRAM_BOT_TOKEN -ErrorAction SilentlyContinue
```

Сетевая ошибка не подтверждает недействительность токена: проверьте доступ к Telegram и повторите проверку.

## Где менять поведение

- Telegram-команды, хранение и формат отчёта — `scripts/bot.py`.
- Стратегия и Gemini — `scripts/agent.py`.
- Настройки и логирование — `scripts/config.py`.
- Общая функция `run_demo(seed=42)` — `scripts/local_eval.py`; она возвращает `seed`, `campaigns`, `n_pilots`, `metrics` и при ошибке `error`.
- Пилоты и локальная модель — `scripts/environment.py`; правила итоговой оценки — `scripts/scoring_core.py`.

Прежний `bot_eval` находится только в тестах для сравнения результатов. Отдельного переключаемого адаптера боту больше не требуется.
